# Third party software

## Stockfish

The Android and Windows apps include **Stockfish 19**, the official release builds
`stockfish-android-arm64-universal` and `stockfish-windows-x86-64-universal`, run as
native programs for game analysis.

- Release: https://github.com/official-stockfish/Stockfish/releases/tag/sf_19
- Source code: https://github.com/official-stockfish/Stockfish/tree/sf_19
- License: GNU General Public License v3.0

The web app also uses Stockfish 19 compiled to WebAssembly by
[Stockfish.js](https://github.com/nmrugg/stockfish.js) (GPLv3).
